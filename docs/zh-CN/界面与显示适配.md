# 微信界面与动态显示适配

[English](../en/INTERFACE_AND_DISPLAY.md) · [安装指南](快速开始.md) · [项目首页](../../README.md)

本实验性工具仅可用于你拥有或获明确授权访问的账号和数据。请阅读双语[免责声明](../../DISCLAIMER.md)。

## 连接关系

    MCP 客户端 / AI
        → 本机 stdio MCP 服务
        → 已登录的微信进程及本地数据
        → 将经过身份与范围核验的结果返回客户端

服务不会操作云端微信账号。界面操作要求 MCP 进程与微信窗口位于同一 Windows 交互桌面，并且 MCP 能发现该窗口。

## 微信窗口区域

| 界面区域 | 服务如何使用 |
| --- | --- |
| 微信主窗口 | 核实唯一且已登录的客户端进程。出现多个相符的主窗口时会判为目标不明确。 |
| 会话列表 | 用于受控的实时观察和候选会话发现。隐藏数据库记录本身不能证明它是当前界面中的正确会话。 |
| 当前会话标题栏 | 在界面操作前辅助核对会话身份；导航或窗口变化后需要重新核对。 |
| 消息／渲染区域 | 在支持的界面路径和几何校验通过后，提供可见消息或附件观察。 |
| 输入框与发送按钮 | 仅在目标、控件和草稿检查通过后用于受控提交。本地返回成功不等于远端送达回执。 |

微信账号由账号所有者本人登录。MCP 正常工作时，主窗口保持已登录并最小化；关闭弹窗和文件对话框。不要同时用鼠标、第二个 Computer Use 控制器和 MCP 操作微信。

## 动态窗口大小、分辨率和 DPI

显示器不要求采用单一固定分辨率。运行时会观察当前微信根窗口、渲染客户区、DPI 缩放、桌面原点、剪裁、语义控件、当前会话和目标控件。每次界面操作都使用新测量；窗口移动、尺寸不匹配、目标被剪裁或证据不明确时会停止。它不会复用其他电脑的坐标，也不依赖一次性的比例缩放。

2.5.2 验收中的自动化几何矩阵覆盖 90 种合成情况：6 种窗口／显示尺寸（800×600 至 3840×2160）、5 种 DPI 比例（100% 至 250%）和 3 种桌面原点，另有一个小于最低窗口尺寸时拒绝操作的案例。这些是自动化几何测试，并不代表已实测所有显示器、微信主题、窗口状态或远程桌面。验收期间没有更改真实显示器分辨率。

首次部署时调用 wechat_status 查看本机当前的 layout_calibration，包括根窗口矩形和渲染客户区。这只是一次观察，不是永久坐标校准。后续每个界面工具都会自己检查。如果微信窗口位于其他虚拟桌面、不可见、有重复主窗、被对话框遮挡，或几何证据未通过，就停止该界面路线并报告原因。

### 推荐的显示设置流程

1. 使用正常且尺寸非零的 Windows 桌面，并让微信主窗口保持登录。
2. 关闭临时对话框。界面操作运行时，不要切换远程桌面分辨率、显示缩放或微信窗口位置。
3. MCP 客户端和微信必须位于同一交互式 Windows 会话。Session 0 服务或另一个虚拟桌面不能满足此要求。
4. 让 wechat_status 观察当前布局。无需采用固定窗口尺寸，也不要手动编辑坐标。
5. 移动／缩放窗口、更改 DPI 或重新连接远程桌面后，再做一次只读状态检查；每个界面工具仍会单独测量目标。
6. 几何校验失败表示该界面操作当前不可用。不要降低完整性检查，也不要反复猜坐标点击。

## 推荐的工具串联

| 任务 | 调用顺序 |
| --- | --- |
| 首次部署 | 阅读 wechat_first_deploy_and_tool_chains → wechat_capabilities → wechat_status |
| 群成员变动后找群 | 新调用 wechat_search(scope="groups") → 在微信界面核对准确群身份 → 使用当前 UI 会话引用 |
| 读取消息 | 核对准确会话 → 有界读取 → 用已核验证据区分 self、other、unknown |
| 监听所选会话 | wechat_read_new_messages(start_from="now") 建游标 → 用保留的游标调用 wechat_watch_new_messages → MCP 客户端按请求时长继续轮询 |
| 回复 | 必须先核对目标与 other 发话者 → 检查完整回复及未发送草稿 → 通过授权路径发送 → 必要时查询操作状态 |
| 查看附件 | 对已核验字节调用 wechat_get_attachment → 否则使用 wechat_view_attachment_handoff 并在 Computer Use 中打开准确的微信预览 |
| 原生 @ 提及 | wechat_send_at_username 返回 Computer Use 交接；工具本身不会发送提及 |

wechat_watch_new_messages 是有界轮询，不是推送通知或常驻 daemon。每次调用 1–60 秒，最多 16 个所选会话，默认检测间隔 5 秒。若消息方向或身份为 unknown，应暂停该会话的回复流程。

## 常见结果

| 返回值 | 含义与下一步 |
| --- | --- |
| TARGET_NOT_VISIBLE | MCP 进程在当前交互桌面找不到主窗口。先处理桌面／会话问题，再尝试界面路线。 |
| TARGET_AMBIGUOUS | 找到多个候选主窗口。处理重复客户端窗口后重新检查。 |
| unverified_layout | 当前几何或目标证据不足。停止该界面操作并调整窗口状态。 |
| readstore_index_invalid | 停止数据库读取。不要改写或重建微信 WAL／SHM 文件。 |
| outcome_unknown | 保留操作 ID，并查询状态或检查新鲜界面证据。不要盲目重发。 |
