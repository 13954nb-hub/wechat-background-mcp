## 版本与系统要求

微信 Background MCP 2.5.2 是本地实验性 MCP 服务。唯一安装包是面向 Windows x64、CPython 3.12 x64 的 wheel：

- [下载 2.5.2 安装包](https://github.com/13954nb-hub/wechat-background-mcp/releases/download/v2.5.2/wechat_background_mcp-2.5.2-cp312-cp312-win_amd64.whl)
- 文件大小：554,022 字节
- SHA-256：**95df0b182ba67f85664a592acba70a1c6c920e56f8b86cb9466759b4ee278cd7**

| 组件 | 支持版本 |
| --- | --- |
| 操作系统 | Windows 10 或 11，x64 |
| Python | CPython 3.12 x64，建议使用独立虚拟环境 |
| 微信桌面端 | 微信 Windows 4.1.13.12 x64 |
| 客户端完整性校验 | 已安装的 Weixin.dll SHA-256 必须为 **e3240bf8a4d00593a4b3e6ce6c8b6ac26897622c27f410f6655c4eee17cb3b6d** |
| MCP 传输 | 本机 stdio 进程，且与微信位于同一 Windows 交互桌面 |

界面上显示的版本号不足以证明兼容。设置器会检查所选程序路径、DLL 大小和 SHA-256、PE 布局、Python 架构以及已安装的 MCP 版本。任一项不匹配都会停止。

## 微信客户端版本与下载

MCP wheel **不包含微信专有安装程序**。请从腾讯获取微信：

- [微信 Windows 官方下载页](https://pc.weixin.qq.com/)
- [腾讯 CDN：WeChatWin_4.1.13.exe](https://dldir1v6.qq.com/weixin/Universal/Windows/WeChatWin_4.1.13.exe)
- [4.1.13.12 的独立版本记录](https://github.com/cscnk52/wechat-windows-versions/releases/tag/v4.1.13.12)

腾讯 CDN 地址是可能变更内容的系列下载地址，不是不可变的 4.1.13.12 历史归档。公开版本记录称，该地址在 2026-08-21 提供过 4.1.13.12 安装包，其安装包 SHA-256 为 **74570be9fa1dbabf11a901e00e24279e139ade7277da4c8852d60faa6403345e**；后续记录显示同一地址已提供其他构建。该版本页只是第三方元数据，不托管安装包。请只从腾讯或腾讯授权来源下载，检查实际文件，并让 MCP 设置器校验安装后的 Weixin.dll。安装包哈希与安装后 DLL 哈希是两项不同检查。

如果安装链接现在提供了更新构建，请勿修改 MCP 指纹、屏蔽微信更新或悄悄降级客户端。请停止部署，等待未来 MCP 版本明确测试并支持可官方获取的微信构建。

## 下载并校验 MCP 安装包

在 PowerShell 中下载 wheel，并在安装前核对 SHA-256：

    $url = 'https://github.com/13954nb-hub/wechat-background-mcp/releases/download/v2.5.2/wechat_background_mcp-2.5.2-cp312-cp312-win_amd64.whl'
    Invoke-WebRequest -Uri $url -OutFile .\wechat_background_mcp-2.5.2-cp312-cp312-win_amd64.whl

    $wheel = Join-Path $PWD 'wechat_background_mcp-2.5.2-cp312-cp312-win_amd64.whl'
    $expected = '95df0b182ba67f85664a592acba70a1c6c920e56f8b86cb9466759b4ee278cd7'
    $actual = (Get-FileHash -LiteralPath $wheel -Algorithm SHA256).Hash.ToLowerInvariant()
    if ($actual -ne $expected) { throw "Wheel SHA-256 mismatch: $actual" }

创建独立 Python 环境并安装：

    py -3.12 -m venv "$env:LOCALAPPDATA\WeChatBackgroundMCP\venv"
    $python = "$env:LOCALAPPDATA\WeChatBackgroundMCP\venv\Scripts\python.exe"
    & $python -m pip install $wheel
    & $python -m pip check

不要使用其他 AI 软件捆绑的 Python。将环境和 MCP 状态目录放在源代码仓库之外，并在重启间保持路径稳定。

## 生成 MCP 客户端配置

配置工具只输出配置，不会改写 Codex 设置或修改微信。先列出正在运行的微信程序路径，再明确指定用户选中的路径：

    $configure = "$env:LOCALAPPDATA\WeChatBackgroundMCP\venv\Scripts\wechat-mcp-configure.exe"
    & $configure --list-running
    & $configure --weixin-exe 'C:\actual\path\Weixin.exe' --format codex

其他 MCP 客户端使用 --format json。输出包含本机 Python 程序和路径环境变量。检查输出后，先备份所选客户端的现有配置，只新增或更新该 MCP 项，保留其他设置。存在多个微信安装时，工具不会自行猜选；它也不会写入客户端配置。

重启 MCP 客户端后，依次调用 wechat_capabilities 和只读 wechat_status，并检查状态结果里的 cleanup.restored=true。状态检查可能会在微信进程中短暂租用并还原一个版本锁定的访问门字节，详见[安全说明](../../SECURITY.md)。

## 首次使用工作流

1. 阅读 MCP 提示词 wechat_first_deploy_and_tool_chains。
2. 检查 wechat_capabilities 和 wechat_status。
3. 搜索群聊或联系人时重新调用 wechat_search。数据库结果只是候选项；打开会话前请在微信界面核对准确身份。数据库会话键不能直接用于发送。
4. 只读取用户指定的会话和时间范围。发话者分为 self、other、unknown；只有已核实为 other 的消息才可作为回复候选。
5. 发送前重新核对准确目标和完整未发送内容。本地操作成功不代表远端已送达。
6. 多会话任务使用 wechat_multi_chat_reply_loop。wechat_watch_new_messages 是由 MCP 客户端驱动的有界轮询，不是服务端常驻监听器。每次调用等待 1–60 秒，最多支持 16 个所选会话，默认间隔 5 秒。MCP 客户端需要保存游标并继续调用。
7. 原生微信 @ 提及或无法直接读取的附件预览，会返回 Computer Use 交接提示；只能在微信所在桌面使用。MCP 服务不会替客户端启动 Computer Use。

工具目录登记 29 个端点；能力响应把功能分组为 27 个标签，因此两个数字不同。continuous_message_listener 尚未实现。

## 数据与安全

服务在本机操作已登录用户的微信进程和本地数据。部分受控操作会使用版本锁定的进程内访问；发送文件时会将本地原生桥接加载到微信进程。使用前请阅读 [SECURITY.md](../../SECURITY.md)、[原生桥接说明](../../native-src/README.md)、[NOTICE](../../NOTICE) 和[第三方 read-store 归属说明](../../THIRD_PARTY_READSTORE.md)。

返回给 AI 客户端的聊天内容可能按客户端设置发送到其模型服务商。不要公开上传聊天数据库、消息导出、账户数据、状态目录、诊断日志或截图。本项目是非官方项目，与腾讯或 OpenAI 没有隶属关系。
